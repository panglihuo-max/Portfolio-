Optional folder — keep it next to index.html.

Your profile photo and gallery photos are already built into index.html.
Put files here only if you want to:
  - use your own .mp4 videos in "Featured videos" (e.g. assets/my-video.mp4), or
  - swap the profile photo (e.g. assets/new-photo.jpg).
Then write the file name in SITE SETTINGS inside index.html.
